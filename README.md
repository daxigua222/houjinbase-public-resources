# 日本の法人情報を確認するときのメモ

公開情報を参照するときに、確認した対象・出典・日付を残すための小さな資料集です。
法人の同一性を調べるメモと、集計表を比較するメモを分けて用意しています。

## 使い方

1. [確認チェックリスト](CHECKLIST.md)から、目的に合う項目を選びます。
2. [記録用CSV](reference-log.csv)を自分の作業場所へコピーします。
3. 分からない項目は空欄のままにせず、「未確認」と記録します。

CSVには架空の資料を使った記入例が一行あります。実在の法人や統計を表すものではありません。
顧客名、担当者の個人情報、契約内容などを、この公開リポジトリへ投稿しないでください。

## 公開情報の参照先

| 参照先 | 確認する目的 | 読むときの注意 |
| --- | --- | --- |
| [国税庁法人番号公表サイト](https://www.houjin-bangou.nta.go.jp/) | 商号・所在地・法人番号の基本情報を調べる | 検索条件や履歴の表示条件を確かめる |
| [Houjinbase データレポート](https://www.houjinbase.com/reports/) | 法人に関する公開情報の集計例を読む | 対象期間、地域、数える対象、注記を一緒に読む |

名称が一致するだけで同じ法人と判断したり、件数が一致するだけで同じ集計と判断したりしないことが、この資料の出発点です。
数字や検索結果を引用するときは、参照先と確認日を添えてください。

## この資料について

Houjinbase編集部がメンテナンスしています。上記のHoujinbaseは当編集部の運営サイトです。
国税庁その他の公的機関による公式資料ではありません。
この資料は公開ページを読むための整理用メモであり、個別の法人の状態や資料の正確性を保証しません。

文章の作成・整理にはAIを使用しています。リンク先の表示や説明を優先し、誤記や古いリンクに気付いた場合は該当箇所をお知らせください。
